# This is Going Away

Sadly... Github is requiring 2FA. For security reasons, I don't use 2FA. Basically, I used 2FA before, and when my phone broke, I lost all accounts. I cannot in good conscience link people to accounts that I can completely lose control over at any time without notice. At least most US tech monolopolies give you notice when they are going to terminate your account (under normal circumstances), so I can link people to accounts on those. It is still not ideal, they do, in fact, ban accounts without notice or reason without recourse. However, it is unlikely enough that I still sometimes link to those accounts. But 2FA is completely outside of my control. I've had several phones (really old, but those are the ones I use) break. I cannot afford to link people to accounts that I can just lose access to.

I guess this project also isn't really that useful. I was thinking of making a full-blown engine. I got distracted and didn't really. I'm thinking I might not do open source anymore. Even though I appreciate open-source, nobody I contacted to work together was interested. And then nobody ever reads my code or ideas. So it's somewhat of a waste of time.

But I might do some online work in javascript. The client side will be visible to the user. I guess you could copy that code. If I find another open source platform that does not require 2FA, I might upload the client-side code. On the other hand, AI is getting good enough to write code better than programmers anyway, so I'm not sure it's even all that useful going forward.

We will see.

## This Project

Below Deck BlackJack is a very simple game submitted to [https://itch.io/jam/lowrezjam-2024].

For this jam, the game has to be 64x64 resolution.

I basically was having issues with Godot (maybe I don't understand how to use it for low res).
